# Sportvatar

Web app for [Sportvatar](https://sportvatar.com) — customizable sport avatars on the Flow blockchain (sibling project of [Flovatar](https://flovatar.com)).

- Laravel 12 / PHP 8.4+, Filament admin (`/admin`, wallet allowlist), built-in Flow event indexer (`flow:catchup`, `flow:stream`, `flow:process`).
- Cadence contracts: `cadence/contracts` (mainnet account `0xca5c31c0c03e11be`).
- Pack codes v2: see `docs/PACK-CODES-V2.md`.

History starts at the 2026 relaunch. Licensed web fonts are not included in this repository and are provisioned on the server.
